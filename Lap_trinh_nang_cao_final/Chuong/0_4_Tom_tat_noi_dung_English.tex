\begin{center}\bfseries\large ABSTRACT\end{center}
\vspace{0.5cm}
RoomHub is a classroom and meeting-room booking system with separate user and administrator roles. Users explore rooms by floor and time slot on a visual map, inspect capacity and equipment, and submit a request from the selected room. Administrators review requests, manage rooms and maintenance, configure booking rules, and control room-specific access permissions.

The project emphasises business logic and object-oriented design. A Java 17 service built with Spring Boot and JPA provides REST operations and uses an H2 database during development. The Android application uses React Native and TypeScript and can operate with local data or the Java service according to its configuration. Booking rules and access checks are implemented in the service layer; server-side writes are revalidated inside database transactions.

For rooms equipped with a smart lock, an administrator or an authorised user may create a seven-digit temporary PIN. The application records the PIN and its validity interval before attempting delivery. Once a OneIoT session is connected, the mobile client publishes the corresponding MQTT message. Broker publication is not treated as proof that the physical lock has applied the PIN. Automated application tests and a Java integration test are present; a release build has also been checked on an Android device in local mode.
