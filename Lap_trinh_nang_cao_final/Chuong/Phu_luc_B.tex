\section{Danh sách REST API của dịch vụ Java}
Mọi điểm cuối trừ đăng nhập yêu cầu tiêu đề \texttt{Authorization: Bearer <token>}. Lỗi nghiệp vụ trả về mã 400, thiếu hoặc sai token trả 401, không đủ quyền trả 403, thân phản hồi có dạng \texttt{\{"message": "..."\}}.

Gateway khóa cung cấp thêm hai điểm cuối: \texttt{GET /api/lock/status} trả trạng thái kết nối OneIoT, lệnh và phản hồi gần nhất; \texttt{POST /api/lock/temp-password} nhận \texttt{\{roomId, roomName, code, passwordId, startTime, endTime\}} và trả mã 202 kèm \texttt{\{accepted, trait, requestId, passwordId, publishedAt\}}.

\section{Hướng dẫn cài đặt và chạy thử}
\paragraph{Cài bản dùng ngay.} Tải mã nguồn và cài APK có sẵn lên điện thoại Android đã bật gỡ lỗi USB:
\begin{lstlisting}[language=bash,numbers=none]
git clone https://github.com/xwomen1/classroom-booking.git
cd classroom-booking
adb devices -l
adb install -r \
  ./code/booking_classroom/release/booking_classroom-v1.0.apk
\end{lstlisting}
Có thể gửi trực tiếp tệp APK sang điện thoại và cho phép cài ứng dụng không rõ nguồn gốc. Tài khoản mẫu: quản trị viên \texttt{admin/1}, giảng viên \texttt{user/2}.

\paragraph{Chạy bản phát triển.} Trong thư mục \texttt{code/booking\_classroom} chạy \texttt{npm ci}, \texttt{npm start}; ở cửa sổ khác chạy \texttt{adb reverse tcp:8081 tcp:8081} và \texttt{npm run android}. Kiểm tra mã nguồn bằng \texttt{npm test -{}- -{}-runInBand}, \texttt{npm run lint} và \texttt{npx tsc -{}-noEmit}.

\paragraph{Chạy dịch vụ Java.} Trong thư mục \texttt{code/booking-server} chạy \texttt{mvn spring-boot:run}; dịch vụ lắng nghe cổng 8080, dữ liệu lưu tại \texttt{./data/booking}, giao diện quản trị cơ sở dữ liệu ở \texttt{/h2-console}. Để ứng dụng dùng máy chủ, đặt \texttt{ENABLE\_REMOTE\_SYNC = true} và sửa \texttt{REMOTE\_API\_BASE\_URL} trong \texttt{src/core/config/runtimeFlags.ts} thành địa chỉ LAN của máy chạy dịch vụ.

\paragraph{Chạy gateway khóa.} Trong thư mục \texttt{tunghv3}, nhập token thử nghiệm vào \texttt{ONEIOT\_TOKEN} của \texttt{gateway\_config.py}, cài thư viện bằng \texttt{python -m pip install -r requirements.txt} rồi chạy \texttt{run\_gateway.ps1}. Trong màn ``Quản lý khóa'' của ứng dụng, nhập địa chỉ \texttt{http://<IP máy tính>:8135}.
