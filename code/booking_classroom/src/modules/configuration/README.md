# Module: Configuration

**Người dùng chính:** Admin.

## Chức năng con

- Cấu hình khoảng thời gian được phép đặt phòng.
- Cấu hình quy định hủy phòng.
- Cấu hình thông báo.
- Quản lý các tham số nghiệp vụ thay vì ghi cố định trong giao diện.

## Giá trị nghiệp vụ ban đầu

- Đặt trước ít nhất 1 ngày và không quá 3 ngày.
- Admin chỉ đổi phòng trước giờ bắt đầu ít nhất 30 phút.
- Mã khóa tạm thời có biên hiệu lực 10 phút trước và sau phiên sử dụng.

Các module khác đọc cấu hình này nhưng không tự thay đổi quy tắc.

**Hiện trạng:** mới tạo khung, chưa triển khai code nghiệp vụ.
