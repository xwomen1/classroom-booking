# Module: Notifications

**Vai trò:** Admin và User.

## Chức năng con

- Thông báo yêu cầu booking mới cho Admin.
- Thông báo duyệt, từ chối, đổi phòng hoặc hủy cho User.
- Nhắc lịch lấy khóa/thẻ và thời gian sử dụng phòng.
- Thông báo bảo trì hoặc thay đổi cấu hình liên quan.

Kênh gửi và thời điểm gửi sẽ tuân theo module `configuration`.

**Hiện trạng:** mới tạo khung, chưa triển khai code nghiệp vụ.
