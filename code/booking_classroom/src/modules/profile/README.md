# Module: Profile

**Vai trò:** Admin và User.

## Chức năng con

- Xem thông tin cá nhân.
- Sửa thông tin cá nhân được phép thay đổi.
- Hiển thị vai trò và trạng thái tài khoản.

Việc đổi mật khẩu được xử lý bởi module `auth`.

**Hiện trạng:** đã xem, sửa và lưu cục bộ họ tên, email, số điện thoại và đơn vị/khoa.
